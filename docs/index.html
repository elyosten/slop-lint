slop-lint

A prose linter for Russian and English. Find formulaic wording, see its position in the text, and get a concrete editing suggestion.

Source code and setup instructions

Check text locally

npm ci
npm run build
node dist/cli/index.js --lang all article.md

Run these commands from a local checkout. The CLI and TypeScript core are available now, with five starter rules per language. The npm package and interactive browser demo are still in development.

Processing runs on your computer. Findings are editing suggestions and do not establish who wrote a text.

По-русски

slop-lint находит шаблонные обороты в русских и английских текстах и предлагает правки. Сейчас доступны ядро и CLI. Инструкции запуска и план развития — в репозитории.
